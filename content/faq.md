# 常见问题 / FAQ

## A &raquo; 平台使用问题

### A1. 如何使用该平台？

1. 在使用平台之前，你需要注册一个账号。

::tip
**如何注册账号**

请前往[欢迎页](/hello)后单击「**立即体验**」按钮。
::

2. 注册账号后会自动登录，或者可单击右上角**登录**按钮进行登录。
3. 根据你想要进行的操作做出决定
   1. 如果你想查看当前周目的一些基本信息，以及自己在游戏内的信息，请转到[主页](/)
   2. 如果你想开启服务器，或者查看服务器当前的状态等，请转到[服务器](/instance)页面
   3. 如果你想查看排行榜信息，请转到[排行榜](/board)页面
   4. 如果你想查看当前和过往周目的详细信息，请转到[周目](/terms)页面

### A2. 如何开启服务器？

1. 转到[服务器](/instance)页面
2. 单击下方操作栏中的「**创建并开启**」按钮
3. 在弹出的窗口中，点击「**确定**」
4. 等待 5~10 分钟
5. 启动客户端，输入页面上显示的 IP 地址加入服务器

### A3. 服务器状态有哪些？含义是什么？

::tip
**什么是服务器状态**

![fuwuqizhuangtai](/images/article/faq/instancestatus.png)
::

标 ⭐️ 的是常见状态

- **准备中**是指服务器正在创建中，还未创建好
- ⭐️**在线**是指服务器已经开启，可以进入游玩
- ⭐️**离线**是指服务器目前还不存在，需要创建
- **空转**是指服务器关闭了，但是主机仍然在运行，此时属于不可玩但仍然计费状态，所以叫做「空转」

::tip
**关于空转**

空转状态有两种可能性，一种是正在准备服务器相关的资料，另一种是服务器崩溃并不能再正常运行。

后面这种情况持续得越长，经济损失越大。因此，Lab 设有对空转状态的检测机制，当空转状态持续超过了 10 分钟，那么主机会被强制删除，变为**离线**状态。
::

- **关闭中** - 略
- **启动中**是指服务器刚刚创建，正在启动，且此时还没有部署
- **等待服务器响应**是指正在获取服务器的在线信息，通常用来判断是「在线」还是「空转」

### A4. 关于绑定

#### A4a. 如何绑定 Minecraft ID？

::tip
**提示**

Minecraft ID 就是你的正版游戏名
::

**你在注册的时候填写了游戏名吗？**

- 是 => **绑定前，是否更换过游戏名？**
    - 是 => 1
    - 否 => 5
- 否 => 1

1. 登录你的账号
2. 单击右上角你的头像
3. 选择「绑定 Minecraft ID」项
4. 输入你的 ID，单击「确定」
---
5. 使用相同的 ID 登入服务器，你会看到如下图所示的信息

![](/images/article/faq/verify-message.png)

6. 输入指令 `/seati lab verify` 完成绑定

#### A4b. 绑定 Minecraft ID 有什么用？

- 体验 Lab 的所有功能
- 游戏数据的记录的对接

- 绑定以后，你可以在网页上查看游戏的统计数据，并以你的身份使用网页聊天功能（目前暂未开放）。

#### A4c. 绑定后，如果我更换了游戏名，会发生什么？

更换游戏名后，原有的绑定将会自动失效，你需要重新按照 A4a 中的叙述进行绑定才能继续使用功能和查看数据。

在游戏内，例如时长计算等会继续以你的新的游戏名进行记录，此过程无需担心。

然而，先前的数据将会保持在你先前的游戏名下不会改变，因此，**为了能够正常显示数据，请联系管理员进行一次迁移。**

## B &raquo; 平台相关概念

### B1. Lab 是一个什么样的平台？

::tip
**简答**：一个为 Seati 玩家所设计的，用来<u>操控服务器</u>和<u>检索相关信息</u>的网页。
::

Lab 这一平台始于 2022 年受 SomeBottle 的启发所推出的具有类似功能的平台。后来该平台因为 SEATiDE 借用 Oasis 的独立主机而能稳定持久运行而关停。如今经过重新编写，于 2024 年 8 月再次推出。

Lab 平台借助阿里云（阿里巴巴旗下 IaaS 平台）提供的 API，允许玩家在网页端自行创建服务器，并调用预先编写好的脚本进行部署、启动服务器，从而达到在数分钟内即可进入服务器的效果。与此同时，自行开发的服务器插件会对玩家的数据进行记录并管理服务器的释放（当前为连续 1h 无人在线则自动停服），达到与 Lab 平台对接并最终节省成本的目的。

### B2. Lab 是免费的吗？

服务器本身和 Lab 均为免费性质，不需要玩家花一分钱即可正常使用。部分 Lab 的功能需要玩家绑定游戏名后使用。
